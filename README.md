# 🇧🇩 Desh IT

Desh IT is a modern web application built with **Next.js**, **Tailwind CSS**, and **Framer Motion**.  
It is fully responsive, fast, and optimized for production.  

---

## 📂 Project Structure
/app
/components → Reusable UI components
/public → Static assets (images, icons, etc.)
/styles → Global styles
layout.js → Main layout wrapper
page.js → Home page

## 🛠️ Tech Stack
- [Next.js](https://nextjs.org/) – React Framework  
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS  
- [Framer Motion](https://www.framer.com/motion/) – Smooth animations  
- [Google Fonts – Plus Jakarta Sans](https://fonts.google.com/) – Custom typography
